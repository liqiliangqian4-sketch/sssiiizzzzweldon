A / 测绘

确认 JL 2 门年份、现有支点与门槛包络，测量一体梁 / 包装基准。

B / 结构

按弯矩与脚步落点选分段区；不默认正中对半。内套管 / 键位传递弯扭，机械紧固防松。

C / 造型

用斜切、阶梯搭接或鞍形桥盖连接前后视觉；盖件不代替结构承载。

D / 放行

同一载荷规格对比一体梁，测静载、偏载、扭转、疲劳、复装与运输后间隙。

负责人
